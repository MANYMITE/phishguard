Run phishing drills on people who said yes.
Store zero credentials. Ever.

PhishGuard is a free, open-source phishing-awareness platform: realistic fake portals, personal unguessable links, live click/submit stats, an instant teaching page — and a database that cannot hold a password, enforced by the test suite itself.

source docs MITPython 3 + Flask

why phishguard

Credential-harvesting toolkits (BlackEye & friends) ship the mechanics with none of the guardrails — you can't put them on a résumé, and you can't legally run them on real people. PhishGuard keeps the training value and hard-codes the ethics into the source:

🚫 zero-credential storage

The submission handler never reads the password field. Tests post a canary password and byte-scan the DB file to prove it never touched disk.

✅ consent gates

Campaigns and participants require explicit consent, re-validated twice — route and database layer.

🔗 unguessable links

Every participant gets a personal random token. A forged token looks exactly like a missing page.

🎭 10 fictional portals

Webmail, VPN, banking, payroll, health, airline and more — themed, clone-of-nothing, always with an honest banner.

🖥️ hacker-console UI

ASCII banner, numbered menu, template grid — the terminal experience, driving a legitimate product.

🌍 any network

LAN mode plus one-command tunnels (Cloudflare / Pinggy / ngrok / localtunnel). Links auto-carry the public host.

quickstart

  1. Get it — git clone https://github.com/MANYMITE/phishguard.git && cd phishguard
  2. Set up — ./install.sh (or: python3 -m venv .venv; pip install -r requirements.txt)
  3. Activate — . .venv/bin/activate
  4. Set your admin password — export PHISHGUARD_SECRET_KEY="pick-a-long-random-string"
  5. Verify — bash scripts/verify.sh (13 automated end-to-end checks)
  6. Run — python run.py → web panel at http://127.0.0.1:5000 — or python phishguard-cli.py for the terminal UI
# the whole drill in one line, terminal style:
python phishguard-cli.py   # → [01] quick drill → pick portal → consent → link

safety model

⚠️ PhishGuard is for authorised awareness training only: simulations delivered to people in your organisation who consented, on systems you own. Using it — or any tool — to phish real credentials from unconsenting people is illegal in most jurisdictions.
Honest pages

Every simulation shows an unremovable banner: “training exercise — nothing you type is saved.”

Teaching moment

Submitters land on an education page — check senders, hover links, refuse urgency, go direct, report.

Privacy by design

Stored data: names, work emails, event counts, hashed user agent. Delete the SQLite file and everything is gone.

faq

Is this a phishing tool?

No. It's the opposite: a training tool that borrows phishing's teaching mechanics. It refuses to run without consent at three separate layers, shows an honest banner on every simulation, and its database has no column that could store a password — enforced by tests that byte-scan the DB after posting a canary credential.

Could someone use it to steal real passwords?

Not with this codebase. Submissions are dropped without being read; only clicked/submitted events (plus a hashed user agent) are recorded. Someone determined to harvest credentials would have to rewrite the app — at which point they're just writing their own phishing kit, not using PhishGuard.

What are the portals clones of?

Nothing — deliberately. “Acme Webmail”, “Meridian Bank”, “CorpNet VPN” etc. are fictional. Realistic mechanics, no trademark cloning, so the project stays publishable and legal everywhere.

Does it send emails?

Not yet — V1 delivery is deliberately manual: you are the sending engine, and consent-logged SMTP is on the roadmap. Nobody gets an email they didn't agree to.

Where does it run?

Anywhere Python 3 runs: any Linux distro, macOS, WSL, Windows, or one-click on Render. Data lives in one SQLite file you can delete when the exercise is over — that removes everything.

Is it really free?

MIT-licensed, no accounts, no telemetry, no paid tier. GitHub Pages hosts this site; Render's free tier (or your own box) hosts the app.

host it on render (free)

No server needed — deploy straight from GitHub to a public HTTPS URL (https://phishguard-xxxx.onrender.com). The generated PHISHGUARD_SECRET_KEY is your admin password (Render → Environment).

# or self-host on any Linux box:
git clone https://github.com/MANYMITE/phishguard.git && cd phishguard
./install.sh && . .venv/bin/activate
PHISHGUARD_SECRET_KEY="your-secret" gunicorn -w 2 -b 0.0.0.0:8000 wsgi:app
