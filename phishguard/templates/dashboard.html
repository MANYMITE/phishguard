How a drill runs

  1. Create a campaign and tick the consent box.
  2. Add each consenting participant by name + email.
  3. Copy each participant's personal, unguessable link and send it to them however you agreed (email, chat).
  4. Watch clicks/submissions land here, then walk each person through their personal “you were caught” teaching page.

Links contain a random token, so they can't be guessed or enumerated — a wrong token looks exactly like a missing page. V1 delivery is deliberately manual; consent-logged SMTP sending is on the roadmap.
